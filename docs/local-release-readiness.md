# 로컬 검증 및 배포 전 체크리스트

## 로컬에서 검증한 범위
- Instagram은 Jev 판정 뒤 관련 후보가 3개 미만이면 대체 검색어가 있는 경우 Brave를 한 번 더 호출한다. 중복 URL은 재판정하지 않으며 보강 실패 시 기존 결과를 보존한다.
- Chrome 실검색: 예시 릴스 링크 → 남친 상황극 → 남자친구 상황극 보강 → 결과 2개, 썸네일 데이터 1개. 커플 공감 숏드라마 → 커플 공감 상황극 보강 → 0개. iced coffee recipe → 결과 5개, 썸네일 데이터 5개. 조회수는 모두 미확인.
- TikTok: 상위 8개 후보의 공개 페이지에서 재생수와 커버를 확인한다. iced coffee 검색(최소 10만)에서는 Chrome에 영상 4개 표시, 모두 재생수·썸네일 데이터 포함.
- Instagram의 비공개 조회수를 표시하려면 시청 수치를 제공하는 인가된 데이터 출처가 필요하다. 현재 기능 범위 밖.

## 공유 배포 승인 후 진행할 것
- [ ] Python 기본 HTTP 서버 대신 운영용 서버 구성. 인증, HTTPS, 허용 호스트 및 비밀 주입 방식 결정.
- [ ] 검색 사용자별 요청 제한, 전체 동시 호출 상한, 제공자별 타임아웃 및 429 대응. 키워드+플랫폼 단위 짧은 캐시 검토.
- [ ] YouTube, Brave, OpenRouter 사용량/예산 알림 설정. Instagram 요청은 기본+보강으로 각각 최대 2회; TikTok은 소셜 후보 검색 외에 공개 페이지 최대 8개를 조회.
- [ ] 외부 API 실패율, 빈 결과율, 썸네일 표시율을 기록하되 키·참조 URL 원문과 입력 파일 내용은 로깅하지 않음.
- [ ] 배포 대상 환경에서 키워드, URL, 파일 업로드 및 오류 모드 재검증. Flucto의 대체 검색 가용성을 별도로 검증.
