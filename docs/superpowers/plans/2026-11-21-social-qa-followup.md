# 멀티플랫폼 검색 개선 — 설계 및 작업지시서

범위: 로컬 앱만 변경. YouTube 동작 보존. Instagram 비공개 조회수 추정 금지. 라이브 검증에는 설정된 API 키만 사용, 키 값 보고 금지.

## 작업 큐 (위에서 아래로)
- [x] 1. TikTok: app.py에서 공개 재생수가 최소값 이상인 후보와 미확인 후보를 분리. 미달 제외. index.html에서 최소 재생수 선택 및 확인된 결과의 재생수순 제공. 0회와 null 구분.
- [x] 2. Instagram: Brave 첫 검색 후보 3개 미만이면 동의어나 짧은 검색어로 최대 한 번 보강. URL 중복 제거 후 Jev 판정 1회. 보강 호출 실패 시 기존 후보를 보존하고 사용자에게 표시.
- [x] 3. UI: 이미지가 없거나 실패하면 대체 표시. 제목, 검색 입력, 플랫폼별 안내를 현재 기능에 맞춘다.
- [x] 4. QA: 전체 유닛 테스트 및 Chrome 반복 검증. 실제 YouTube/TikTok/Instagram 검색과 모의 경계값·이미지 실패 검증을 분리 보고한다.

완료 조건: 재생수 검증 경계값, 미확인 분리, 보강 실패 상태, 썸네일 실패 UI의 회귀 테스트 통과. 외부 출처에서 못 얻은 데이터는 제한 사항으로 보고하며 성공으로 세지 않는다.
