# 영상 형식 및 보기 모드
- YouTube contentDetails.duration, TikTok 공개 메타데이터 video.duration을 초로 정규화. Instagram은 릴스로 분류한다.
- 검색 후보를 180초 이하 / 초과 / 미확인으로 구분. 전체에서는 그룹으로, 숏폼/롱폼 선택 시 일치 그룹만 표시. 공식 YouTube Shorts 여부가 아님을 알린다.
- 그리드 기본, 리스트 선택 가능. 같은 검색 결과와 정렬을 유지하고 로컬에 보기만 기억한다.
- 단위 테스트와 Chrome에서 그룹 경계, 보기 전환, 선택 유지, 미확인 재생수 분리를 확인한다.
